========================================================================
 GUÍA DE IMÁGENES PARA SEÑAFÁCIL (Lengua de Señas Colombiana - LSC)
========================================================================

¡Hola estudiantes y profesores!

Para colocar imágenes o fotografías reales de las señas colombianas:

1. Guarda tus fotos o ilustraciones dentro de esta carpeta (`img/`).
2. Puedes usar formatos: .jpg, .png, .gif o .svg.
3. Te recomendamos nombrar las imágenes en minúscula (ejemplo: `hola.png`, `gracias.jpg`, `agua.png`).
4. Si cambias el nombre o la extensión de una imagen, abre el archivo `script.js` y busca el listado `wordsData`. Allí puedes actualizar la propiedad `imagen` de cada palabra.

Ejemplo en script.js:
{
    id: "hola",
    word: "Hola",
    category: "saludos",
    imagen: "img/hola.png",  <-- Cambia la ruta aquí si usas fotos reales
    explicacion: "Mueve la mano abierta de un lado a otro cerca de la cabeza a la altura de la sien.",
    ejemplo: "👋 ¡Hola! ¿Cómo estás?"
}

¡Éxitos en la Feria Escolar de Ciencia y Tecnología! 🇨🇴✨
